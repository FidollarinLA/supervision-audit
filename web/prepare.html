① 原始对话与工具轨迹

使用 OpenAI 风格的 messages / tools，每条记录提供 id 和 source。支持多轮文本、显式 reasoning_content、多个工具调用与匹配结果。工具不会执行。

② 目标模板与实际分词

在本地命令行，用 Teich / Hugging Face 适配层加载目标 tokenizer。它提供原生模板文字、带类型的候选区间与真实 token 偏移。浏览器直接导入这份结果，不在这里猜测模型词表。

node prepare.mjs raw.json --tokenizer LOCAL_TOKENIZER --out result.json

演示的 Qwen 原生模板记录已经实际分词。推理演示使用项目自定义模板，仅用于验证推理策略。
