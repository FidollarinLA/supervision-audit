TRAINING DATA WORKBENCH

从对话轨迹准备训练数据，并门禁每一个训练目标。

SupervisionAudit 不是只读 labels 的审计器。它对标 Teich 的模板 / 掩码流程：标准化轨迹、选择监督内容、生成 unshifted labels、控制序列长度，再在训练前拒绝错误监督。

开始准备训练数据 ↗ 打开监督审计门禁
1. 轨迹

校验 OpenAI 风格 messages / tools 与调用 ID 配对

2. 模板

可选 Teich / HF 原生模板与真实 tokenizer 偏移

3. 标签

MoonBit 六类策略 + 长度策略生成 labels

4. 门禁

审计通过后导出 JSONL，并可逐 token 核对

ACCEPTANCE CHECKLIST

评审验收清单

按条目核对可运行证据；不代替官方评分，也不宣称已通过终审。

  1. 产品入口 — 打开 / 看到工作台叙事，主 CTA 指向 prepare.html，审计在 audit.html。
  2. 准备主路径 — 默认 Qwen 演示生成 45 目标；策略预设切到 final-only 为 24；可下载 JSONL。
  3. 第二模板族 — 准备页「加载 Zephyr 风格演示」接受 zephyr-typed-v1（自写 WordLevel，非 Hub 词表）。
  4. 长度策略 — 试用 truncate-complete-turns；超长且无完整回答轮则整批拒绝。
  5. 门禁证据 — 准备页「查看 token 证据」进入审计页，或导入已门禁文档。
  6. 离线评审包 — npm run demo:reviewer → artifacts/reviewer-demo/evidence.json 与 training.jsonl。
  7. 本人报名 — 报名终稿由参赛者独立填写（截止以通知为准）；AI 不代写。
