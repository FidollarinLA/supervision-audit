## 提交前需要核对

1. 报名方向为“新项目申报－参与季度评选”，名称与仓库一致，不能继续使用 MoonMask 仓库地址。
2. 本人最终申报书应符合问卷的一页 Markdown、至少三个完整场景等要求；问卷明确要求“不要使用 AI 编写”。当前草稿不是满足此要求的最终件。
3. 不能把“预训练原型”写成“已验证真实训练器或模型效果”。真实 collator / tokenizer 适配、损失掩码参考对照仍需完成。
4. 参赛者需要能解释 label shift、-100、attention mask、来源边界、为何保留 review 状态，以及 MoonBit 与 JavaScript 的职责。

## 最终验收与奖项仍有的风险

- 稳妥起见，完成 Mooncakes 发布和干净项目安装验证。五月技能章程将其列为验收要求，十月官网的简化清单未逐项列出所有发布要求，应以本期正式章程及工作人员解释为准。

- 浏览器真实视觉检查尚未完成。已做模拟 DOM 行为与 HTTP 检查，但当前浏览器连接超时，电脑操作工具也禁止控制 Codex 自身，未生成真实界面截图。
